# Бэклог сноса

Работы сноса, отложенные словом пользователя (5 нояб.). Оценка читает их вместе с реестром; взятая работа отсюда удаляется.

| работа | факт | как брать |
|---|---|---|
| Сокращение тестов по всему репо | На трёх малых границах хватило 53–68 % тестов. Ожидаемо минус 250–350 случаев и около 1 % строк: на всём репо метод не проверен | Отложенные случаи и мутации, файлы тестов по делам, отдельной работой поверх снесённого |
| Находки опыта с мутациями | Лишняя проверка `typeof` в `workers/github`; границы 60 с, 60 мин и 48 ч в `workers/ledger` без теста; `spawnSync` без предела в тесте `tools/send`; странные формы отказа в `tools/send`. Отчёт снят до второго круга, живо подтверждён только `spawnSync` | Проверить на нынешнем коде, живое разобрать вместе с сокращением тестов |
| Широкая граница со сменой контракта | Смена контракта разрешена везде через слепого архитектора, но ни одной такой границы ещё не было, выигрыш не замерен; 30 имён `provides` без единой строки `uses` не разобраны | Одна граница через слепого архитектора: у каждого имени факт использования, 30 имён первыми; замер токенов и сложности до и после |
| Выбор старта не по карте | Размер и правки по карте плохо предсказали выигрыш (ρ ≤ 0,25). Предложение ретро: старт по признакам — своя реализация того, что умеет платформа или сосед, почти копии, слой пересылки. Пользователю не предлагалось | Предложить как правку шага «оценка» |
| Мелочи между частями | `CALL_MS` 120 с в `protocol` и 8 с в `workers/releases`; `LIMIT_MS` с двумя значениями; `st.kernel.*` в тестах модулей Host; двойные написания полей SDK не проверены опытом | Отдельной маленькой работой, написания SDK — опытом на настоящем SDK |
| Живые флоу и эталоны выложенного флота | `scripts/flow-*` — 1897 строк, единственный неснесённый код: проверяются только на живом флоте | Один агент на тестовом флоте, живая проверка на каждом шаге |
