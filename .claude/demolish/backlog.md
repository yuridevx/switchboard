# Бэклог сноса

Работы сноса, отложенные словом пользователя (5 нояб.). Оценка читает их вместе с реестром; взятая работа отсюда удаляется.

| работа | факт | как брать |
|---|---|---|
| Сокращение тестов по всему репо | На трёх малых границах хватило 53–68 % тестов. Ожидаемо минус 250–350 случаев и около 1 % строк: на всём репо метод не проверен | Отложенные случаи и мутации, файлы тестов по делам, отдельной работой поверх снесённого |
| Широкая граница со сменой контракта | Смена контракта разрешена везде через слепого архитектора, но ни одной такой границы ещё не было, выигрыш не замерен | Одна граница через слепого архитектора, замер токенов и сложности до и после |
| Живые флоу и эталоны выложенного флота | `scripts/flow-*` — 1897 строк, единственный неснесённый код: проверяются только на живом флоте | Один агент на тестовом флоте, живая проверка на каждом шаге |
