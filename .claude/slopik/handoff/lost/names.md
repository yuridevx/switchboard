## Расхождения

**А. Правка в продолжении ответа прошлой зависает. Снято: настоящий поток не доходит.**
- Что: `await c.edit("a"); c.edit("b")` — вторая правка застаёт `cycle` законченного цикла: `.finally` ещё не сработал. Цикл не запускается, ответа нет, `settled()` возвращается сразу, запись не уходит до следующей правки.
- Опыт: красный тест через контракт упал на нынешнем коде (`x.b` не записан). Сверка: 47 из 800 сценариев «старое ok · новое зависло», других расхождений нет.
- Почему снято: `settings` создают только `personal` и fleet. За ответом `personal` показывает тост (`web/packages/ui/src/personal.ts:18`). Инструменты fleet идут в `host.request` или отвечают сразу (`host/modules/fleet/src/tools.ts:123-124,160-169,180-182`). Второй правки в продолжении нет нигде. Со следующей правкой новым событием — 0 расхождений из 800 (`diff-settings-real.out`).
- Код не менялся. Несделанная правка и тест — в `snyato-chain-edit.patch`; с этой правкой тест не прогонялся, она снята по уточнению раньше прогона.
- Для главной сессии: ловушка контракта. Первый вызывающий, кто напишет две правки подряд через `await`, получит вечное ожидание.

**Б. arrange: «Без проекта» не последней в записи.** Старый код ставил её последней при показе, новый идёт по записи. 610 из 5000 на записях, собранных руками. Снято: в коде продукта `prefs.set` зовёт только цикл настроек, запись проектов правят только функции records (board и fleet), и они держат её последней. Так же и в версии до e331885; более ранние и запись на проде не смотрел.

**В. dropSessions: before из самого блока.** 2870 из 5000 на таких входах. Снято: `rowDrag` ищет before среди `stay(rows)`, а они блок исключают (`web/packages/board/src/drag.ts:235,257,266`); другого вызова `s.drop` нет.

**Г. setLabel пишет только свой раздел.** Было `{sessions:{…}, machines:{}}`, стало `{sessions:{…}}`. 27 836 из 40 000 по записи целиком, 0 по тому, что видит читатель. Снято: оба поля в типе необязательны, в коде продукта запись читает только `labelOf`. Для сведения: значение в хранилище стало короче.

**Д. Экран labels без адреса.** Старый показывал окно с адресом `@` и мог записать имя машине с пустым именем; новый не рисует ничего. Снято: контракт — `callsign` или `machine`; карточка всегда передаёт callsign (`web/packages/card/src/wide.tsx:47`, `narrow.tsx:93`).

**Е. Правка, пришедшая за время чтения цикла, входит в этот цикл.** Единственный красный из старых тестов: одна запись вместо двух, значение `[1, 2]` то же. Не потеря: итог совпал, записей меньше.
