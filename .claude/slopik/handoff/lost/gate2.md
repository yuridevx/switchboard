## Потеря

**П1. Дверь gate: кадр с `id: ""` потерял отказ словом** (3 случая опыта). Старый: `!f?.id` → bad_frame, база не тронута. Новый: `id === undefined` пропускает пустой id, кадр обслуживается. Снаружи: `POST {"type":"gate.redeem","id":"","v":1,"invite":…}` без пропуска гасит одноразовое приглашение; keys.invite пишет строку. Вред: по правилу всех обработчиков (`!id`) такой кадр — кадр без id, «ответить некому», а одноразовый секрет уже потрачен, второй раз пропуск не выдать. Первый проход снял запись причиной «отправителей с пустым id нет»; на открытой двери эта причина не действует: любой вход реален, отказ словом обязателен.

Красный (red.txt): ожидался bad_frame, пришло `"ok": true, "result": {"key": "host.laptop.27eb.…"}`. Правка: index.ts:44 `if (!id)`. Код 400 оставлен: Р6.
