# Реестр слопиков

Единственный судья, когда двое заявляют одно. Ведёт старший. Контракт модуля — в его `module.json`, сюда не копируется. Строка появляется, когда понятие разобрано.

## Понятие → владелец

| понятие | владелец | примечание |
|---|---|---|
| машина и имя адреса | `protocol` | `machineOf`, `nameOf` |
| вход службы флота: кадр → ответ, отказ словом, строка журнала | `gate` | рядом с `entrance`; реализация — ветка `slopik-door`, ждёт слияния |
| сессия запроса по callsign | ядро Host | реализация — ветка `slopik-session`, ждёт слияния |
| кого доставать пушем | `host-push` | |
| подписки браузеров и доставка пуша | `push` | |
