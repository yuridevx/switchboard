# Реестр слопиков

Единственный судья, когда двое заявляют одно. Ведёт старший. Контракт модуля — в его `module.json`, сюда не копируется. Строка появляется, когда понятие разобрано.

## Понятие → владелец

След — выражение `git grep -E`: где копия правила выдаёт себя вне владельца. След будит хозяина, а не запрещает: совпадение он разбирает как обычного кандидата.

| понятие | владелец | примечание | след |
|---|---|---|---|
| машина и имя адреса | `protocol` | `machineOf`, `nameOf` | `lastIndexOf\("@"\)` |
| вход службы флота: кадр → ответ, отказ словом, строка журнала | `gate` | рядом с `entrance`; реализация — ветка `slopik-door`, ждёт решения | `class Refusal` |
| сессия запроса по callsign | `host` | реализация — ветка `slopik-session`, ждёт решения | `host\.session\(req\.callsign` |
| кого доставать пушем | `host-push` | | |
| подписки браузеров и доставка пуша | `push` | | |
