# web-core

## Решения

| что | решение | причина |
|---|---|---|
| `onRoster` в шести модулях | оставлена | шесть разных дел по одному событию |
| `usesName` в Host — `uses` в `web-core` | оставлена | вердикт архитектора: разбор уже у владельца, осталось выражение над публичным полем; результаты разные, это работа выполнения, а не суд |
| `alerts` `bytesOf` — `push` `unb64u` | оставлена | стандартный base64url, разные среды; опыт: на длинах 1–65 байт совпали с дополнением и без |
| `kernel.ts:404` — `journal` `permission_denied` | оставлена | совпадение формы |
| `chat` `Rows.tsx:279` — `settings` `general.tsx:40` | оставлена | шаблон JSX |
| `FakeRelay` не проверяет форму callsign | оставлена | roster стенду даёт сам тест, двери у подделки нет |
| «имя » в причине: Host срезает, страница оставляет | различие открыто | текст снаружи, закреплён тестами обеих сторон; рекомендация — оставить |
| `config ?? {}`: страница прощает, Host падает TypeError | различие открыто | на настоящих манифестах не видно; рекомендация — оставить |
| `refused`, `refusal` на страницах и в Host | оставлена | разные таблицы слов под свои экраны |
| `vitest.config` Worker-модулей | оставлена | конфигурация пакетов, законная копия |
| совместные правки `manage`, `machine`, `remote`, `shell`, `prefs`, `records`, `labels` | оставлена | след коммитов сноса, а не связь без контракта |
