# Судьбы пар

Отклонённую пару не разбирают снова. Ведёт старший. Судьбы — в скиле `slopik`.

| пара | судьба | причина |
|---|---|---|
| `tools/send/send.mjs` `split("@").pop()` — `machineOf` | оставлена | файл без зависимостей по контракту, копируется на машину как есть |
| `host-push` — `push` | оставлена | разные дела: кого будить и как доставить; расхождение в 5 сценариях из 7 |
| `link` в `workers/points` — в `workers/releases` | оставлена | разные ключи и пути, общее — только вызов `presign` |
| `fleet-client` — `link` в relay | оставлена | совпадение формы: маршрутизация и одно соединение |
| `onRoster` в шести модулях | оставлена | шесть разных дел по одному событию |
| вход Worker'ов ×6, `class Refusal` ×5, журнал ×6 | слита | ветка `slopik-door`; развилки: `why`, кадр `reply`, порядок id, `from` |
| сессия запроса: chat, manage, points | ждёт решения | ветка `slopik-session`; слово отказа: `bad_spec` или `offline` |
| сессия запроса: logins, profiles | ждёт решения | заморожены; один кадр без `callsign` выключает модуль на машине |
