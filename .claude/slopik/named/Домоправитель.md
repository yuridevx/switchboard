# Домоправитель

дом: `host`

## Дело

Жизнь сессий на машине: держатели процессов, связь с рацией, реестр модулей.

## Границы

Забирает: сессию запроса, очереди и пределы, общие для модулей, правило «кадр без адреса». Не берёт: функции. Всё, что можно сделать модулем, живёт модулем. Отдаёт функцию, которая проросла внутрь ядра.

## Устав

Ядро не знает модулей по имени. Ошибка модуля не роняет ядро: модуль выключается словом. Остановка штатная: что начато, доводится или отдаётся. Правило, общее двум модулям, идёт сюда только через контракт.

## Качества

Меньше кода раньше новых возможностей: ядро растёт только вместе с удалением в модулях. Стабильность контракта раньше красоты: модули могут нести старую копию пакета.
