# Сигналы

Выводы исследования 6 нояб. Числа получены почти везде на Java, Python и людях: это ориентир, а не закон. Факт проверяется по построению, кандидат требует чтения. Запрос на правку собирается только из первой таблицы.

## Повод к действию

| сигнал | почему |
|---|---|
| забытый близнец: А изменён, Б позже получает похожую правку | поздняя пропагация связана с исправлениями |
| две копии расходятся на одном входе | конкретный контрпример |
| конфликт объявлений одного факта в слоях | ложных около 7 % на аналоге |
| кадр без приёмника или отправителя | 8 из 19 реальных ошибок на аналоге |
| роль вне разрешённого модуля, ресурс мимо владельца | факт по построению |
| `uses` расходится с реальными импортами | факт; правится код, правка манифеста — отдельное событие |
| цикл, неиспользуемый экспорт, новая подтверждённая пара | точный факт |
| открытая дверь: правило есть у одной копии, у другой копии вход шире | опыт сноса: самые тяжёлые потери |

## Повод прочитать

Разбирает старший. Подтверждённая пара становится целью.

| сигнал | предел |
|---|---|
| движущаяся пара между модулями | цена дубля сосредоточена здесь: большинство клонов неподвижны |
| совместные правки модулей без структурной связи | история короткая; группировать по задаче, смотреть долю, агрегировать по модулям; клиент и эндпоинт меняются вместе законно |
| почти-клон, `jscpd --semantic`, близость имён и форм, рост числа модулей на понятие | точность 0.57–0.68 в лучшем случае |
| произведение повторов вдоль пути | тревога, а не прогноз |
| доля пропавших строк в правке, одна функция вместо нескольких, шов двух домов, ветка ОС | сигнал риска правки: ρ около 0,5 на 14 границах сноса, намёк |

## Сравнить с прошлой сборкой

Сообщений на действие, варианты пути, период опроса. Связи с исходами не найдено, абсолютных порогов нет.

## Не повод

Общая плотность дублей и неподвижные клоны внутри модуля; счётчики запахов, Scattered Functionality, Hub-Like, Instability, Decoupling Level; цикломатика, Maintainability Index, Code Health, LCOM, глубина модуля; truck factor, темы LDA, кластеризация как гейт; зелёные тесты, доля слияний, мнение модели без проверки; длина устава и число скилов; ширина границы; выживший мутант.

## Что видят детекторы здесь

Замер 6 нояб. на `5e1ac6d`, четыре размеченных дубля:

| детектор | вход Worker-модулей | окно подтверждения | секция выбора | `machineOf` |
|---|---|---|---|---|
| `scan.mjs`, Жаккар ≥ 0,5 | да, 5 пар | да | да | нет |
| `jscpd --similarity 0.6 --min-nodes 10` | 1 пара | да | нет | нет |

Однострочный дубль короче порога любого детектора: его находит только обход от понятия. Версию `jscpd` закреплять точно: 5.4.1 и 5.4.2 меняли шкалу и смысл опций.

`scan.mjs` читает все функции и считает почти-клоны по шинглам нормализованных токенов; вложенные функции и их обёртки не сравниваются. Ошибка измерителя уже стоила: «0 почти-клонов» при настоящих 46 и 124 ложные пары функции с собственным колбэком. Снимочные скрипты дают скачки, смотри разбивку по модулям.

## Обход

| обход | след |
|---|---|
| исключить файл, поднять порог, подавить комментарием | дифф конфигурации проверок |
| разрезать функцию ниже порога | рост мелких функций, падение пар при тех же строках |
| переименовать, переписать другой формой | второй детектор другого принципа |
| вынести копию туда, где не считают: тесты, скрипты, соседний модуль | фиксированный широкий набор файлов |
| обёртка: общий модуль создан, старые копии стали прокси | ни один старый символ не удалён |
| слить через булев флаг | рост ветвлений, значение всегда разное у вызывающих |
| удалить поведение или тест | откат тестов, опыт, удалённые экспорты |
| поправить снимок | снимки владельца вне задачи |
| поправить модель, а не код | правка манифеста как отдельное событие |
