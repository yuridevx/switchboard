# Сигналы

Выводы исследования 6 нояб. Числа получены почти везде на Java, Python и людях: это ориентир, а не закон. Факт проверяется по построению, кандидат требует чтения. Запрос на правку собирается только из первой таблицы.

## Повод к действию

| сигнал | почему |
|---|---|
| забытый близнец: А изменён, Б позже получает похожую правку | поздняя пропагация связана с исправлениями |
| две копии расходятся на одном входе | конкретный контрпример |
| конфликт объявлений одного факта в слоях | ложных около 7 % на аналоге |
| сообщение без получателя или отправителя | 8 из 19 реальных ошибок на аналоге |
| роль вне разрешённого модуля, ресурс мимо владельца | факт по построению |
| объявленные зависимости расходятся с реальными импортами | факт; правится код, правка манифеста — отдельное событие |
| цикл, неиспользуемый экспорт, новая подтверждённая пара | точный факт |
| открытая дверь: правило есть у одной копии, у другой копии вход шире | опыт сноса: самые тяжёлые потери |

| отказ вызывающему, а работа продолжается за его спиной | опыт 6 нояб.: один разговор на двух машинах |
| предел обработчика больше предела вызывающего | снаружи «не вышло», часы спустя выходит |
| повтор вне списка, разрешённого проектом | факт по построению |
| новое правило в уставе проекта | старые скилы его не знают: сверить |

## Повод прочитать

Разбирает старший. Подтверждённая пара становится целью.

| сигнал | предел |
|---|---|
| движущаяся пара между модулями | цена дубля сосредоточена здесь: большинство клонов неподвижны |
| совместные правки модулей без структурной связи | история короткая; группировать по задаче, смотреть долю, агрегировать по модулям; клиент и эндпоинт меняются вместе законно |
| почти-клон, `jscpd --semantic`, близость имён и форм, рост числа модулей на понятие | точность 0.57–0.68 в лучшем случае |
| произведение повторов вдоль пути | тревога, а не прогноз |
| доля пропавших строк в правке, одна функция вместо нескольких, шов двух домов, ветка ОС | сигнал риска правки: ρ около 0,5 на 14 границах сноса, намёк |

## Сравнить с прошлой сборкой

Сообщений на действие, варианты пути, период опроса. Связи с исходами не найдено, абсолютных порогов нет.

## Не повод

Общая плотность дублей и неподвижные клоны внутри модуля; счётчики запахов, Scattered Functionality, Hub-Like, Instability, Decoupling Level; цикломатика, Maintainability Index, Code Health, LCOM, глубина модуля; truck factor, темы LDA, кластеризация как гейт; зелёные тесты, доля слияний, мнение модели без проверки; длина устава и число скилов; ширина границы; выживший мутант.

## Что видят детекторы

Однострочный дубль короче порога любого детектора: его находит только обход от понятия. Версию детектора закрепляй точно. Измеритель проверяй на уже снятых дублях: «ноль находок» бывает ошибкой счёта.

## Управление и работа

Эти роды не считаются числом: перечень мест механический, сам спор видно только при чтении пути.

Управление: шаблон показал 31 % решающих строк и все стороны спора у 3 находок из 16. Вместо поиска слов — три таблицы, спор виден на их строках:

- запрос → предел вызывающего, предел обработчика, что идёт после отказа;
- слово закрытия → реакция каждого клиента, на всех языках;
- сбой → кто поднимает → что сказано вызывающему.

Свидетель — на настоящих соседях: подделка соседа прячет спор, опыт снимает ложное.

Работа: клаузы и лексический отбор поймали 2 из 19 пар; настоящие конфликты говорят разными словами. Читай пары по потокам: что во что передаётся. Находка только со свидетелем: ситуация, где два правила дают разный ответ. Отсев: тот же объект, тот же контур, явное исключение, скил лишь строже устава. Копия без свидетеля — метка, а не находка. Триггеры скилов сверяются набором фраз.

## Обход

Красная команда, 6 нояб.: 32 атаки при полном знании контроля. До правок 13 прошли без следа, и одного нового имени хватало. После: 11 из 13 дают след, настоящее сведение — только одну пару на чтение.

| обход | след |
|---|---|
| исключить файл, поднять порог, переписать вердикт | правка контроля в задаче |
| разрезать функцию ниже порога | рост мелких функций, символ жив |
| новое имя, другая форма, новая папка | символ жив, литералы на месте |
| вынести копию в тесты, стенд, скрипт, к соседу | символ жив, литералы на месте; литералы считаются во всём дереве |
| слить через булев флаг | новый флаг решает ветки |
| удалить поведение или тест, поправить ожидание | снято проверок, красный откат тестов |
| поправить манифест, а не код | правка манифеста вне операции над домом |

Автоматика не отличает от настоящего сведения две атаки: обёртки с новыми именами у обеих копий и тихую потерю разметки при живой паре. Их находит только чтение, поэтому ревизор читает верх подозрительных и случайную долю сведённых.

Второй детектор страховкой не считается: `jscpd` теряет ту же пару вместе с основным. Страхуют другие свойства — символ, литералы, проверки, — а не другой детектор сходства.
