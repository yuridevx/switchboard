# Привязка к проекту

Минимум — один файл. Скил `slopik-<проект>` нужен, когда есть что сказать о тестах, выпуске и заморозке.

`.claude/slopik/config.json`:

```json
{
  "houses": "node .claude/slopik/houses.mjs",
  "ignore": "^generated/",
  "slots": 4,
  "scan": "команда для языка, который не разбирает ядро",
  "assert": "выражение строки с проверкой в тестах; по умолчанию expect("
}
```

`houses` — команда файлом, а не строкой с кавычками; печатает `[{"name": "api", "dir": "packages/api/"}]`. `scan` печатает `[{"file", "name", "line", "toks": [...], "lits": [...]}]`; без него ядро разбирает JS и TS, на другом языке снимок отказывает словом, а не отвечает «чисто». `npm i` в папке скила ставит закреплённый `typescript`; `SLOPIK_TS` — другая папка с ним.

`.claude/slopik/registry.md`:

```markdown
# Реестр

## Дома

| дом | дело |
|---|---|
| `api` | принимает запросы клиентов |

## Понятие → владелец

| понятие | владелец | примечание | след |
|---|---|---|---|
| разбор адреса | `core` | | `lastIndexOf\("@"\)` |
```

След — выражение `git grep -E`; пустой след ничего не будит. Первый проход: `census`, строки реестра, `pass '{"confirmed":0,"rejected":0,"queue":0}'`.

Запись прохода: `pass` с полями `confirmed`, `rejected`, `queue`, по желанию `waiting`, `failed`. Команды — из корня репо; `--root` указывает другой. Состояние — `~/.slopik/<репо>/`.

Пул worktree — `.claude/worktrees/slopik-<слот>`, вне отслеживания.
