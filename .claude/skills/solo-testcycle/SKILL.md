# Цикл тестирования

Цель: часть X закрыта тестами по плану, система проходит план, открытых находок 0.

```
план → триаж → имплементация → прогон → находки ─┐
                                   ▲             │
                                   └─────────────┘  пока находки есть
```

| шаг | скил | готово, когда |
|---|---|---|
| план | solo-testplan | страницы проверены, карта покрытия без сирот |
| триаж | solo-testtriage — карта | у каждого сценария уровень, тест или «прогон» и решение |
| имплементация | solo-testtriage — исполнение | карта исполнена, дубликатов 0 |
| прогон | тесты затронутых частей и гейт; solo-runtestplan — сценарии «прогон» | у каждого сценария исход, каждый красный записан |
| находки | solo-bugtriage | открытых находок 0 |

Прогон и находки повторяются, пока в прогоне есть находки. Что находка — определяет solo-bugtriage; не-находки закрываются строкой и круг не держат. Находка, вернувшаяся после фикса, — причина не устранена: назад к фактам. Число находок от круга к кругу не падает — меняешь подход.

## Как работает цикл

- Главная сессия ведёт цикл и пишет итог; работу по частям делают агенты (Agent), Workflow не используются.
- В одних файлах — не больше двух исполнителей; команды в живую систему — один исполнитель.
- Вопросов посреди цикла нет: развилку решаешь по уставу и фактам, решение — одной строкой в итог.

## Итог

Одна сводка пользователю:

- План: флоу, сценарии, нерешённое с закрывающими вариантами.
- Тесты: покрыт, улучшен, добавлен, дубликат убран — числами; тестов и дубликатов до и после.
- Прогон: PASS / FAIL / SKIPPED на первом и последнем круге.
- Находки: харнесс и код, все закрыты; причины — одной строкой каждая. Не-находки — числом по видам.
- Команды и результат.
- Второй проход: план против результата — сделан; хвосты, меняющие поведение, доделаны.

Готово, когда каждый сценарий плана закреплён тестом или прошёл на флоте, в прогоне нет находок и второй проход сделан.
