# Цикл тестирования

Цель: охват X — часть или названные флоу — закрыт тестами по плану, система проходит план, открытых находок 0.

```
план → тесты → выкладка → прогон → находки ─┐
                  ▲                         │
                  └─────────────────────────┘  пока находки есть
```

| шаг | что |
|---|---|
| план | test-plan — охват X |
| тесты | test-cover |
| выкладка | если в плане есть сценарии «вживую»: коммит своих путей → push → CI → `releases.deploy` тронутых частей, keeper — последним |
| прогон | test-run |
| находки | fix-findings |

Готово у шага — по его скилу. Выкладка, прогон и находки повторяются, пока в прогоне есть находки. Находка, вернувшаяся после фикса, — причина не устранена: назад к фактам. Число находок от круга к кругу не падает — меняешь подход.

Главная сессия ведёт цикл; работу шагов делают агенты (Agent).

## Итог

Тому, кто позвал — пользователю или deliver:

- План: охват, флоу, сценарии, нерешённое с закрывающими вариантами.
- Тесты: покрыт, улучшен, добавлен, дубликат убран — числами; тестов и дубликатов до и после.
- Прогон: PASS / FAIL / SKIPPED на первом и последнем круге.
- Находки: харнесс и код, все закрыты; причины — одной строкой каждая. Не-находки — числом по видам.
- Выкладки: коммиты и версии на флоте.

Готово, когда каждый сценарий плана закреплён тестом или прошёл вживую и в прогоне нет находок.
