# Цикл тестирования

Цель: охват X — часть или названные флоу — закрыт тестами по плану, система проходит план, открытых находок 0.

```
план → тесты → выкладка → прогон → находки ─┐
                  ▲                         │
                  └─────────────────────────┘  пока находки есть
```

| шаг | кто | что |
|---|---|---|
| план | форк | test-plan — охват X; слепое расширение страниц — агенты с нуля, их запускает главная сессия |
| тесты | форк | test-cover |
| выкладка | главная сессия | если в плане есть сценарии «вживую»: коммит своих путей → push → CI → `releases.deploy` тронутых частей, keeper — последним |
| прогон | форк | test-run |
| находки | форк | fix-findings |

Главная сессия ведёт цикл. Форк — один на цикл: Agent с `subagent_type: fork`, уже знает код, дизайн и решения пользователя; следующие шаги и круги — сообщением ему же (SendMessage). Форк сам агентов не запускает.

Готово у шага — по его скилу. Выкладка, прогон и находки повторяются, пока в прогоне есть находки; повторяются только сценарии, которых коснулся фикс. Ошибка самого сценария или скрипта — правишь и прогоняешь его, полного круга нет. Находка, вернувшаяся после фикса, — причина не устранена: назад к фактам. Число находок от круга к кругу не падает — меняешь подход.

## Итог

Тому, кто позвал, — пользователю или deliver:

- План: охват, флоу, сценарии, из них дописанные слепым расширением, нерешённое с закрывающими вариантами.
- Тесты: покрыт, улучшен, добавлен, дубликат убран — числами; тестов и дубликатов до и после.
- Прогон: PASS / FAIL / SKIPPED на первом и последнем круге.
- Находки: харнесс и код, все закрыты; причины — одной строкой каждая. Не-находки — числом по видам.
- Выкладки: коммиты и версии на флоте.

Готово, когда каждый сценарий плана закреплён тестом или прошёл вживую и в прогоне нет находок.
