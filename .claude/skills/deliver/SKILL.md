# Делай

Ведёт главная сессия в персоне архитектора (`.claude/architect.md`).

Цель: принятое сделано и проверено вживую — каждая строка «Готово» прогнана числом на флоте, открытых находок 0, регрессия не хуже «до», второй проход сделан.

«Поправь» и «поработай над» начинаются с диагностики — факты из журнала, причина, слой, — затем шаг «вход».

| шаг | что делается | готово, когда |
|---|---|---|
| вход | строки «Готово» — из блока «Порядок реализации» принятого дизайна; у плана в разговоре и у «поправь» — пишешь сам по диагностике, план правки проходит гейт персоны до кода; части и флоу изменения; снимок «до»: `npm test`, `live-etalons`, `flow-*` тронутых частей | у каждой строки число «до» |
| код | главная сессия; порядок по зависимостям: protocol → Worker-модули → ядро Host → модули Host → web → keeper | `npm run gate`, typecheck и тесты тронутых частей зелёные |
| слепой архитектор | только по слову пользователя («слепой архитектор», «пройдись архитектором» по диффу): агент `architect` (Agent, `subagent_type: architect`), новый, на дифф — коммиты или пути, охват; код правишь по его отчёту | находок гейта 0 |
| выпуск | снимки тронутых экранов (`npm run shots`, жесты — `npm run drag`) → `release check` → коммит своих путей → push → CI → выкладка из своего worktree на зафиксированном коммите: `deploy-workers.mjs` тронутых Worker'ов, relay последним → `releases.deploy` тронутых частей: Host, страницы, keeper последним → один живой прогон основных флоу на win и wsl. Код выхода команды — без конвейера; основное дерево не трогаешь. `test-cycle` — только по слову пользователя или когда меняется поток между частями | CI зелёный; находок снимков и живого прогона 0 |
| регрессия | то, что в снимке «до», кроме прошедшего на шаге «выпуск» на том же коде | не хуже «до» |
| прод | Только по слову пользователя, после зелёного теста. До выкладки: в `plan.md` номера отката, в файл — сессии по именам и машинам. Те же шаги с `--env prod`. После: модель отвечает на двух машинах, страницы открываются в браузере, сессии сверены со снимком и журналом флота | у каждой сессии из снимка исход по журналу; карточка прода в памяти |
| второй проход | принятое и гейт персоны против результата | хвосты, меняющие поведение, доделаны; дубликатов, лишних коммуникаций и циклов 0 |
| итог | сводка; карточка флота в памяти — stable-версии | итог сдан |

- Коммит, push и выкладка на тестовый флот входят в «делай»: их делает шаг «выпуск».
- Хвост без смены контракта: тесты и снимок экрана, сразу выкладка; живого прогона нет.
- Шаг пропущен — одна строка с причиной сразу, а не в итоге.
- Смена шага — одна строка пользователю: что сделано и что дальше.
- Факт противоречит принятому — решение пользователя не меняешь: делаешь закрывающий вариант, развилка — в итог.

## plan.md

`<scratchpad>/deliver/<slug>/plan.md` (`slug` — kebab-имя задачи):

- строки «Готово»: число до, число после, статус;
- отложенные половины;
- решения развилок — одной строкой.

## Итог

- Готово: строка → команда → число до и после.
- Гейт: дубликатов, лишних коммуникаций и циклов до и после второго прохода; слепой архитектор, если был, — находок до и после.
- Выпуск: версии на флоте, номера отката, снимки и живые сценарии числами; итог test-cycle, если он был.
- Регрессия: до и после.
- Решения развилок; развилки решений пользователя — с закрывающим вариантом, который сделан.
- Второй проход: хвосты, меняющие поведение, доделаны.
