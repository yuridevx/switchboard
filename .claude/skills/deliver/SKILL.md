# Делай

Принятое становится работающим на флоте, и это доказано числами. Ведёт главная сессия в персоне архитектора. Устав и персона уже в контексте — здесь только порядок, команды и ловушки, которых в них нет.

## Готово, когда

- каждая строка «Готово» прогнана на тестовом флоте: число до и после;
- открытых находок 0, регрессия не хуже «до»;
- второй проход сделан: хвосты, меняющие поведение, доделаны; дубликатов, лишних коммуникаций и циклов 0;
- итог сдан.

## Вход

Работа начинается со строк «Готово»: без них нечем доказать конец.

| запрос | откуда строки «Готово» |
|---|---|
| «делай» по дизайну | блок «Порядок реализации» принятого дизайна |
| «делай» по плану из разговора | пишешь сам по плану |
| «поправь», «поработай над» | сначала диагностика — факты из журнала, причина, слой и нарушенный инвариант; потом строки по ней |

План правки, которого не было в принятом дизайне, проходит гейт персоны до первой строки кода: дубликат дешевле не написать, чем сводить.

До кода — снимок «до» по тронутым частям и флоу: `npm test`, `live-etalons`, `flow-*` этих частей. У каждой строки «Готово» есть число «до»; строка без числа не проверяема — перепиши её.

## Код

Порядок — по зависимостям, от стабильного: protocol → Worker-модули → ядро Host → модули Host → web → keeper.

Фронт проверяется локально на тестовом флоте: `npm run front test`, браузер сессии — по ссылке «снимки». Бекенд к этому моменту уже выложен на тест: запрос, которого флот не знает, получит отказ.

Шаг закрыт, когда `npm run gate`, typecheck и тесты тронутых частей зелёные.

## Выпуск

Коммит, push и выкладка на тестовый флот входят в «делай» — отдельного слова не ждут.

1. Снимки тронутых экранов: `npm run shots`; жесты — `npm run drag`.
2. `release check` — называет, чей номер поднять, до push.
3. Коммит своих путей → push → CI зелёный.
4. Спроси живые сессии репо, кто выкладывает и какие номера заняты (устав).
5. Выкладка — из своего worktree на зафиксированном коммите:
   - `deploy-workers.mjs` тронутых Worker'ов, relay — последним;
   - `FLEET=test node scripts/fleet.ts deploy` тронутых частей: Host, страницы, keeper — последним.
6. Один живой прогон основных флоу изменения на win и wsl.

Закрыт, когда CI зелёный и находок снимков и живого прогона 0.

Ловушки выкладки:

- Основное дерево общее с другими сессиями — его не трогаешь; `npm ci` — только в worktree выкладки.
- Код выхода команды читаешь без конвейера: `| tail` отдаёт код `tail`, а не выкладки.
- Инструмент выкладки сломан — правка коммитом до выкладки, а не руками в worktree: иначе на флоте окажется то, чего нет в истории.

`test-cycle` вместо одного живого прогона — по слову пользователя или когда меняется поток между частями.

Хвост без смены контракта: тесты и снимок экрана, сразу выкладка, живого прогона нет.

## Регрессия

Всё из снимка «до», кроме того, что уже прошло на шаге «выпуск» на том же коде. Не хуже «до»; хуже — новая итерация, не откат.

## Прод

Только по слову пользователя и только после зелёного теста.

- До: номера отката — в `plan.md`; `FLEET=prod node scripts/fleet.ts sessions save <файл>`.
- Выкладка: те же шаги с `--env prod` и `FLEET=prod`.
- После: модель отвечает на двух машинах; `fleet.ts page`; `fleet.ts sessions check <файл>`; журнал флота.

Закрыт, когда у каждой сессии из снимка есть исход по журналу и карточка прода в памяти обновлена.

## Слепой архитектор

Только по слову пользователя («слепой архитектор», «пройдись архитектором» по диффу): новый агент `architect` на дифф — коммиты или пути и охват. Код правишь по его отчёту ты; находок гейта после — 0.

## Второй проход

Один: принятое и гейт персоны против результата. Что делать с хвостами — правило устава.

## По ходу

- Смена шага — одна строка пользователю: что сделано, что дальше.
- Шаг пропущен — одна строка с причиной сразу, не в итоге.
- Факт противоречит принятому — решение пользователя не меняешь: делаешь закрывающий вариант, развилка идёт в итог.

`<scratchpad>/deliver/<slug>/plan.md` — рабочая память на случай сжатия контекста: строки «Готово» с числами до и после и статусом, отложенные половины, решения развилок одной строкой.

## Итог

- **Готово:** строка → команда → число до и после.
- **Гейт:** дубликаты, лишние коммуникации и циклы до и после второго прохода; слепой архитектор, если был, — находок до и после.
- **Выпуск:** версии на флоте, номера отката, снимки и живые сценарии числами; итог test-cycle, если был.
- **Регрессия:** до и после.
- **Развилки:** решённые — одной строкой; задевшие решение пользователя — с закрывающим вариантом, который сделан.

Карточка флота в памяти получает новые stable-версии.
