# Делай

Цель: принятое сделано и проверено вживую — каждая строка «Готово» прогнана числом на флоте win и wsl, открытых находок 0, регрессия не хуже, второй проход сделан.

```
вход → код → архитектор → цикл ⟲ выкладка → регрессия → второй проход → итог
```

| шаг | что делается | готово, когда |
|---|---|---|
| вход | что принято (дизайн, план в разговоре) → строки «Готово» с числом; части по раскладке; снимок «до»: `npm test`, `live-etalons`, `flow-*` тронутых частей | у каждого пункта строка «Готово» и число «до» |
| код | главная сессия, инлайн; порядок по зависимостям: protocol → Worker-модули → ядро Host → модули Host → web → keeper | `npm run gate`, typecheck и тесты тронутых частей зелёные |
| архитектор | architect-review на дифф | дубликатов и циклов 0 |
| цикл | solo-testcycle на флоу, которые изменение добавило или поменяло | находок 0, каждое «Готово» прогнано числом на флоте |
| выкладка | внутри цикла перед каждым живым прогоном: коммит своих путей → push → CI → `releases.deploy` частей | на флоте stable — с текущим коммитом |
| регрессия | то же, что в снимке «до» | не хуже «до»; хуже — новая итерация, не откат |
| второй проход | принятое против результата | хвосты, меняющие поведение, доделаны один раз |
| итог | сводка; карточка флота в памяти — stable-версии | итог сдан |

## Как работает

- Коммит, push и выкладка на тестовый флот входят в «делай»: устав — «реализовать, покрыть тестами, задеплоить и проверить вживую».
- Вопросов посреди работы нет. Развилку решаешь по уставу и фактам, решение — одной строкой в итог.
- Факт противоречит принятому — редизайн в пределах принятой сути. Решение пользователя (🔒, «слово пользователя») не меняешь: делаешь закрывающий вариант, развилка — в итог.
- Пункт не закрывается — разбиваешь на два: первый закрываешь, второй — в `plan.md`, возвращаешься к нему до итога. Открытых пунктов в итоге нет.
- Помощники — агенты (Agent), Workflow не используются. В одних файлах — не больше двух исполнителей.
- Живой флот: один исполнитель команд, свои сессии, модели попроще. Новый номер keeper — в `os/keeper/module.json`; keeper в выкладке последним.
- ✓ — только после числа.

## plan.md

`<scratchpad>/do/<slug>/plan.md` (`slug` — kebab-имя задачи); переживает сжатие контекста:

- пункты: строка «Готово», число до, число после, статус;
- отложенные половины;
- решения развилок — одной строкой;
- коммиты и выкладки.

## Итог

Одна сводка пользователю:

- Готово: пункт → команда → число до и после.
- Архитектор: дубликатов и циклов до и после.
- Цикл: тесты и находки по сводке solo-testcycle.
- Регрессия: `npm test`, `live-etalons`, `flow-*` — до и после.
- Коммиты и выкладки: части и версии на флоте.
- Решения развилок — строками; развилки решений пользователя — с закрывающим вариантом, который сделан.
- Второй проход: сделан; хвосты, меняющие поведение, доделаны.
