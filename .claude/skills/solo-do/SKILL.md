# Делай

Цель: принятое сделано и проверено вживую — каждая строка «Готово» прогнана числом на флоте, открытых находок 0, регрессия не хуже «до», второй проход сделан.

| шаг | что делается | готово, когда |
|---|---|---|
| вход | строки «Готово» — из блока «Порядок реализации» принятого дизайна; у плана в разговоре и у «поправь» — пишешь сам по диагностике, и план правки проходит гейт устава архитектора до кода; части и флоу изменения; снимок «до»: `npm test`, `live-etalons`, `flow-*` тронутых частей | у каждой строки число «до» |
| код | главная сессия; порядок по зависимостям: protocol → Worker-модули → ядро Host → модули Host → web → keeper | `npm run gate`, typecheck и тесты тронутых частей зелёные |
| архитектор | architect-review — дифф | по architect-review |
| цикл | solo-testcycle — части и флоу изменения | по solo-testcycle |
| регрессия | то же, что в снимке «до» | не хуже «до» |
| второй проход | принятое против результата | хвосты, меняющие поведение, доделаны |
| итог | сводка; карточка флота в памяти — stable-версии | итог сдан |

- Коммит, push и выкладка на тестовый флот входят в «делай»: их делает шаг выкладки solo-testcycle.
- Факт противоречит принятому — решение пользователя не меняешь: делаешь закрывающий вариант, развилка — в итог.
