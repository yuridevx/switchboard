# Ревью системы

Гейт, мерка, числа и форма отчёта — в уставе архитектора (`.claude/agents/architect.md`); здесь — порядок работы.

Цель: каждая работа списка — реальная работа над ценностью (пункт 🔒 устава, цель экосистемы или принцип архитектора), и за ней стоит факт в коде; работы сделаны по одной, список пуст.

| шаг | что делается | готово, когда |
|---|---|---|
| охват | вся система или названные части. keeper заморожен — он граница: его читают, но его код в работы не идёт | охват записан |
| ревью | агенты `architect` параллельно, по линзе на агента: коммуникации, модульность, код Worker-модулей, код Host, код web. Вход — охват и линза; по системе архитектор только отчитывается | пять отчётов |
| работы | главная сессия сводит находки линз: одна причина — одна работа. Поля: ценность; факт — место и число, проверенные главной сессией в коде; выигрыш — числа архитектора до → после; цена — какие части затронет. Не работа: без ценности или факта, редакторское, новая защита | у каждой работы четыре поля |
| порядок | нарушения 🔒 устава и гейта архитектора — раньше мерки; внутри — по выигрышу; работа, без которой не сделать другую, — перед ней | порядок записан |
| редизайн | design на работу №1 с шага 2 — факты уже собраны | артефакт опубликован |
| делай | «делай» даёт пользователь, в автономном режиме — вердикт архитектора в проходе design; затем deliver этой работы. «Снять» и «развилка» — в итог. Следующая работа снимается числом, если её закрыла прежняя, иначе — редизайн | список пуст |

| линза | что смотрит |
|---|---|
| коммуникации | каждый поток от инициатора до исхода: переходы, формы сообщений, посредники, запрос вместо кадра, опрос вместо события |
| модульность | граф манифестов и импортов, контракты и владельцы, реестры гейта, циклы, сцепление |
| код | лишнее и мёртвое; защита без метрики пользы и даты пересмотра; самопочинка и запасные режимы; свой механизм рядом с платформой; неявное |

## Артефакт

Один на ревью. Сверху — «Работы»: список по важности, у каждой ценность, выигрыш и статус — ждёт, в работе, сделано, снято, развилка. Ниже — дизайн текущей работы по правилам дизайн-документа устава. У сделанной работы статус «сделано» с числами до и после, её дизайн удаляется.

## Итог

- Числа системы: до ревью и сейчас.
- Работы: сделано, снято — причина одной строкой.
- Развилки: задетые решения пользователя — с закрывающим вариантом; в автономном режиме — и решённые архитектором развилки цены отмены.
