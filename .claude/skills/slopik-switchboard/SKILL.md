# Слопики в Switchboard

Порядок — в скиле `slopik`; здесь — чем его шаги делаются в этом репо. Устав и персона архитектора стоят выше обоих.

| шаг | здесь |
|---|---|
| дом | модуль с `module.json`; `scripts/houses.ts` печатает их для конвейера |
| бэклог | `backlog.md` в памяти проекта и `.claude/demolish/backlog.md`; запись называет файл, значит, дом известен |
| реестр, судьбы, именные | `.claude/slopik/` |
| ветке нужен свой `npm ci` | иначе импорты уйдут в основное дерево и прогон ничего не докажет |
| тесты части | Worker: `npx vitest run` в его папке; Host: `npx vitest run host`; фронт: тесты пакета, `node scripts/web-typecheck.mjs`, снимки тронутых экранов |
| типы | корневой `tsc` Worker-модули не видит: `npx tsc -p tsconfig.json --noEmit` в папке каждого |
| приёмка | `npm run gate`, потребители, чистая копия Linux, keeper с `-race` |
| свежий читатель ночью | `node tools/demolish/cli.ts lost <база> [--comments] <пути>` читается целиком |
| номера | поднимает слопик; код `gate` входит в архив Host, поэтому правка контракта `gate` поднимает и ядро; `release check` до push называет остальное |
| архитектор | агент `architect` с нуля |
| уход и слияние | живой каталог «Выпусков»: старая версия рядом с новой даёт двух владельцев MCP-сервера, сессия не поднимается, манифесты этого не видят; выпуск с `without` |
| заморозка | сейчас: `host/modules/logins`, `profiles`, `fleet`, `web/pult/modules/open`, `profiles`, `accounts` — заявка, а не правка |
| страница итога | Artifact; комментарии читает постоянная сессия цикла |

## Автономия

Слово пользователя 6 нояб.: всё, кроме прода, — полная автономия, прод — только его слово. Сейчас не-прод — это тестовый флот.

- **Выпуск ночью.** Ветка сборки сливается и выкладывается на тестовый флот партией. Перед этим цикл спрашивает живые сессии этого репо, кто выкладывает и какие номера заняты, как велит устав: занято — партия ждёт следующую ночь, цикл не стоит.
- **`main`.** Слияние идёт после приёмки и зелёного тестового флота; проду нужно отдельное слово.
- **Эталоны.** Устав разрешает архитектору менять эталон с пометкой «чьё: код». 🔒 и слово пользователя — нет.
- **Сеть base1 и base2** не дебажится: обрыв там не повод для цели.

## Запуск

Запускает пользователь: `/loop /slopik` в постоянной сессии. Позже запускать будет пульт. Планировщик ОС цикл не ставит.
