# Снос в Switchboard

Порядок — в скиле demolish; здесь — чем его шаги делаются в этом репо. Устав и персона архитектора (`.claude/architect.md`) стоят выше обоих: ведёт главная сессия в этой персоне.

## Карта

```
node .claude/skills/demolish-switchboard/scripts/map.ts                  # все модули
node .claude/skills/demolish-switchboard/scripts/map.ts --boundary a,b   # граница a, b и её соседи
```

Считает из манифестов `module.json` и git; код и тесты — в токенах. Реестр не читает: он концептуальный, его читаешь ты. Границу не проводит: замер 4 нояб. по всей системе показал, что правило «контракт не шире» тянет `web-view`, а правило «умирает имя» расползается на 51 модуль из 52. Ориентир хорошего среза — точки: `points`, `host-points`, `pult-points`, ширина 26 против 43 порознь.

Где карта врёт:

- У `pult-*` в колонке `тесты` стоит 0: их тесты лежат в `web/pult/test`.
- «Ничьи» и «умирает» считают только манифесты. Имена ядра выглядят ничьими; имена, которыми пользуются `scripts/`, выглядят умирающими. Проверяй поиском.
- Модуль для карты неделим: срез части модуля считаешь вручную.
- `коммиты` — за всю историю: массовые правки поднимают весь фронт. Для свежести смотри `git log --since` сам.
- Запускай на свежем `origin/main`.

## Шаги

| шаг demolish | здесь |
|---|---|
| оценка | карта и бэклог в памяти |
| граница | Срез одного дела: Worker-модуль, модуль Host, экран. Контракт, кроме `provides`: кадры, запросы, поля roster, инструменты MCP, ключи хранилища и `env`, `data-module` и `place`. Потребители мимо манифестов: `scripts/`, `tools/send`, агенты |
| общая основа | `protocol`, `web-view`, `web-ui`, `web-core`, ядро Host, `relay`, `gate`: соседом не втягивается. Стартом быть может, если контракт удержит снос |
| тесты | Worker-модули — свои конфиги на `vitest-pool-workers`; Host — стенд с поддельными SDK, Relay, Keeper и часами; web — тесты пакета и снимки настоящего кода (`npm run shots`); keeper — `go test`. Стенд Host идёт и под happy-dom, поэтому срез Host + web может жить в одной среде; Worker-модули — в своей. Файлы границы: `<главный модуль>/test/boundary*.test.ts`. Классы, разметка, стили и вид — не заповедь: меняются на пользу цели; смена вида — снимки до и после на визуальную проверку. Чужой тест или скрипт, который на них смотрит, входит в границу. Мутации: Stryker с vitest, `npm i --no-save` только в своём worktree и не ломая типы. Worker-модули: `vitest.related: false`. Host: `coverageAnalysis: perTest`, предел `until` на прогоне короче. Web: `inPlace: true`, один поток. Части, которые тесты запускают настоящим процессом (`tools/send`), — своим мутатором. Keeper: свой инструмент для Go, не проверялось. Понятия вход, флоу и наблюдаемый исход — из test-plan, без страниц и цикла |
| ожидаемые исключения | закрытый список ветвей восстановления устава, отказ словом и graceful shutdown; крайние случаи не тестируются (устав) |
| источник свойства | слово пользователя, факт или `чьё: код`. 🔒 и «слово пользователя» снятыми не бывают: развилка в итог |
| временные файлы | `<scratchpad>/demolish/<slug>/` |
| дизайн | Контракт тот же — работа маленькая: `design.md` в рабочей папке, без публикации. Контракт, формат или протокол меняются — скил `design` и слепой архитектор: агент заканчивает отчётом, главная зовёт архитектора и продолжает агента через `SendMessage` |
| контракт и данные | Слово пользователя 5 нояб.: контракт, формат хранилища (D1, R2, разделы Host, store страницы, файлы на машинах) и протокол менять можно везде через архитектора. Кодовой совместимости нет; живые данные переносит агент отдельным шагом выпуска. Два параллельных агента не меняют одно имя |
| сверка | `npm run gate`, typecheck, тесты тронутых частей; `node tools/demolish/cli.ts lost <tests> <пути>` — строки и литералы старого кода, которых нет в новом. Есть экраны — снимки и жесты против коммита `tests`: `SHOTS_DOM=<файл> npm run shots` здесь и в соседнем worktree, затем `shots-pair` по их `dist/shots/shots` и `dom-diff` по файлам. Совпадать не обязано: намеренное расхождение названо |
| числа | `node tools/demolish/cli.ts size <старый> <новый> <пути>`: токены, сложность, строки и случаи тестов, десять худших функций. `mutate <таблица> -- <команда>` там, где Stryker не идёт: падают ли леса от названной поломки |
| агент границы | Агент с нуля с изоляцией worktree, по одному на границу (устав). Не пушит, не сливает, не выкладывает; живые флоты, живой Host и keeper этой машины, `wrangler deploy` и `package-lock.json` не трогает; общие стенды `web/pult/test/stand.ts`, `web/packages/core/stand`, `host/core/stand` не меняет, если они не в его границе. Поднимает номера своих модулей. Старый код для опытов — в соседнем worktree от коммита `tests`, не откатом в рабочем дереве. Изоляция отказывает на сложных командах: одна команда git на вызов, без конвейера с циклом, `xargs` и `$()`; файл через Write, скрипт файлом и `node <файл>`, путь буквально, без лишнего `cd` |
| спорные места | Стенды Host и страницы; настоящая зависимость — опыт на настоящем SDK на самой простой модели. Живой флот не трогается. Изменить 🔒 или «слово пользователя» — развилка в итог; исполнить 🔒 — работа |
| выпуск | `deliver`: снимок «до» снимается с main до слияния ветки сборки, строка «Готово» — на каждый тронутый флоу; дальше с шага «выпуск». Замечания агентов «при выпуске» собираешь в `plan.md`. Перед выкладкой спрашиваешь живые сессии этого репо, кто выкладывает и какие номера заняты (устав) |
| итог | гейт — по разделу «Отчёт» персоны |
