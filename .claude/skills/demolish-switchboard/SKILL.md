# Снос в Switchboard

Порядок — в скиле demolish; здесь — чем его шаги делаются в этом репо. Устав и персона архитектора (`.claude/architect.md`) стоят выше обоих: ведёт главная сессия в этой персоне.

## Карта

```
node .claude/skills/demolish-switchboard/scripts/map.ts                  # все модули
node .claude/skills/demolish-switchboard/scripts/map.ts --boundary a,b   # граница a, b и её соседи
```

Считает из манифестов `module.json` и git. Реестр не читает: он концептуальный, его читаешь ты. Границу не проводит: замер 4 нояб. по всей системе показал, что правило «контракт не шире» тянет `web-view`, а правило «умирает имя» расползается на 51 модуль из 52. Ориентир хорошего среза — точки: `points`, `host-points`, `pult-points`, ширина 26 против 43 порознь.

Где карта врёт:

- У `pult-*` в колонке `тесты` стоит 0: их тесты лежат в `web/pult/test`.
- «Ничьи» и «умирает» считают только манифесты. Имена ядра выглядят ничьими; имена, которыми пользуются `scripts/`, выглядят умирающими. Проверяй поиском.
- Модуль для карты неделим: срез части модуля считаешь вручную.
- `коммиты` — за всю историю: массовые правки поднимают весь фронт. Для свежести смотри `git log --since` сам.
- Запускай на свежем `origin/main`.

## Шаги

| шаг demolish | здесь |
|---|---|
| оценка | карта и бэклог в памяти |
| граница | Срез одного дела: Worker-модуль, модуль Host, экран. Контракт, кроме `provides`: кадры, запросы, поля roster, инструменты MCP, ключи хранилища и `env`, `data-module` и `place`. Потребители мимо манифестов: `scripts/`, `tools/send`, агенты |
| общая основа | `protocol`, `web-view`, `web-ui`, `web-core`, ядро Host, `relay`, `gate`: соседом не втягивается. Стартом быть может, если контракт удержит снос |
| тесты | Worker-модули — свои конфиги на `vitest-pool-workers`; Host — стенд с поддельными SDK, Relay, Keeper и часами; web — тесты пакета и снимки настоящего кода (`npm run shots`); keeper — `go test`. Стенд Host идёт и под happy-dom, поэтому срез Host + web может жить в одной среде; Worker-модули — в своей. Файл границы: `<главный модуль>/test/boundary.test.ts`. Классы DOM и разметка в чужих тестах — не контракт: такие тесты входят в границу. Понятия вход, флоу и наблюдаемый исход — из test-plan, без страниц и цикла |
| ожидаемые исключения | закрытый список ветвей восстановления устава, отказ словом и graceful shutdown; крайние случаи не тестируются (устав) |
| источник свойства | слово пользователя, факт или `чьё: код`. 🔒 и «слово пользователя» снятыми не бывают: развилка в итог |
| временные файлы | `<scratchpad>/demolish/<slug>/` |
| дизайн | скил `design`; «Вердикт» даёт архитектор, как в автономном режиме устава. Изменились контракты внутри границы — работа большая, слепой архитектор, так велит design |
| формат хранилища | развилка цены отмены, принцип 20 персоны |
| сверка | `npm run gate`, typecheck, тесты тронутых частей |
| агент границы | Форк главной сессии с изоляцией worktree, по одному на границу (устав). Форк не порождает агентов: дизайн большой работы он заканчивает отчётом, главная зовёт слепого архитектора и продолжает форк через `SendMessage` |
| спорные места | Стенды Host и страницы; настоящая зависимость — опыт на настоящем SDK на самой простой модели. Живой флот не трогается. 🔒 и «слово пользователя» — развилка в итог |
| выпуск | `deliver` с шага «выпуск»: снимки, `release check`, коммит своих путей, CI, выкладка на тест, живой прогон, регрессия, второй проход. Перед выкладкой спрашиваешь живые сессии этого репо, кто выкладывает и какие номера заняты (устав) |
| итог | гейт — по разделу «Отчёт» персоны |
