# Switchboard v2 — карта и состояние

Новая система с нуля по дизайну `docs/designs/from-scratch/index.html` (ветка `v2`). Старая система в корне репо — только источник кода для переноса; её не правим.

## Части

| папка | что | чем проверяется |
|---|---|---|
| `protocol/` | `@sb/protocol`: конверт кадра, адреса, пропуск `флот:номер:секрет`, договор-код (`request`, `frame`, схемы zod), журнал одной формы, общий клиент (`createApi`, `httpTransport`, `socketLink`) | `cd protocol && npx vitest run` |
| `platform/` | Worker `sb2-platform`: объект флота (люди, пропуска, проекты, картина, сокеты страниц) и объект машины (сокеты Host, Keeper, зрителей; доставка кадров). Вход привязки для служб — `platform/src/contract.ts` | vitest в пуле Workers |
| `services/` | Worker `sb2-services` без состояния: вход `POST /call`, сервер MCP `/mcp`, файлы страницы, проход сокетов `/f/*` и `/m/*` в платформу; модули `src/modules/<имя>/`; записи модуля — объект `Records` на модуль и флот (архив — на машину); файлы — R2 | vitest в пуле Workers |
| `host/` | Node + Claude Agent SDK: ядро (сессии, документ, связь, хранилище) и модули chat, accounts, profiles, points, proxy, shell, incidents, remote, machine | vitest со стендом (поддельные SDK, связь, держатели) |
| `keeper/` | Go: служба ОС, держит Host и себя, держатели процессов | `go test` |
| `web/` | React 19 + Mantine 9 + Vite: одна страница, две раскладки; мок флота для прототипа | vitest + снимки `npm run shots` |
| `tools/` | гейт импортов, выкладка, проверка флота | — |

## Правила для исполнителей

- Один адрес флота: всё идёт в службы (`/call`, `/mcp`, `/f/<флот>`, `/m/<флот>/<машина>`, страница); службы зовут платформу привязкой.
- Запрос описан один раз в `protocol/src/contracts/`. Новое имя — туда, с хозяином; обработчик берёт уже проверенный ввод. Договор правится только добавлением; перед правкой перечитать файл: его правят и другие.
- Модуль импортирует чужое только через `@sb/protocol` и вход пакета. Циклов нет: службы → платформа → протокол.
- Каждый запрос несёт `trace`; каждая часть на обратном пути дописывает в `reply.spans` свой отрезок `{part, ms}`; на каждый запрос — одна строка журнала (`logger` из протокола) с `type`, `from`, `to`, `ms`, `ok`, `word`, `trace`.
- Ошибка обработчика — отказ `module_failed` и строка журнала; модуль не выключается. Отказ — `throw new Refusal(слово, причина)`.
- У каждой операции предел (`within`, `CALL_MS`) и штатная остановка.
- Просто: только ожидаемые ветки; без повторов, запасных режимов и обратной совместимости.
- Язык: идентификаторы по-английски, комментарии и тексты интерфейса по-русски.
- Тесты: эталон закрепляет одно свойство на зафиксированном входе. На этой машине: запускать из пути с большой `D:/`; `setTimeout(0)` спит около 10 мс.
- Зависимости уже поставлены в корне `v2/`. Новая зависимость — в `package.json` своей папки и `npm install` из `v2/` (если упал — повторить: рядом могут ставить другие). `npm install-scripts approve <пакет>` — если нужен установочный скрипт.
- Свои файлы — только в своей папке. Не коммитить: коммиты делает главная сессия.
- Ресурсы Cloudflare v2 — с приставкой `sb2-`; ничего не выкладывать: выкладывает главная сессия. Секреты — из `~/.switchboard-dev/v2-cloudflare.env`, не в репо и не в argv.

## Известные хвосты

- Платформа: нет предела ожидания `hello`; нет входа OAuth для внешнего Claude (нужно приглашение с PKCE).
- Службы: чаты Telegram привязаны к флоту одной общей записью; блоки R2 не убираются после удаления точек; стоимость в расходе не считается; `points.history` читает файл целиком.
- Host: нет выгрузки сессии на компьютер без Host; нет пробы папки перед подъёмом; заголовок сессии появляется после первого хода; повтор инцидента после перезапуска может задвоиться; вход Claude по ссылке и коду и перевод Muse перенесены без тестов и вживую не проверены.
- Keeper: тесты под Linux не запускались; под macOS не собирается; служба Windows (не задача при входе) вживую не проверена.
- Страница: перетаскивание не работает пальцем; порядок auto — стрелками; нет фильтра архива по дате; веб-пуш — заглушка без сервис-воркера; имена из настроек не показываются в списках.
- Не настроены: Telegram, ClickHouse, GitHub (секретов нет); CI.
