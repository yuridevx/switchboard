# Опыты

Agent SDK 0.3.311 и Claude Code 2.1.310–2.1.311, Windows и Linux (WSL), 27–28 октября 2026, модель Haiku 5.5. Номера — как в дизайне. Запуск — из этой папки после `npm install`.

| опыт | файлы | что доказано |
|---|---|---|
| 12 | `controller.mjs`, `step.mjs`, `drop.mjs` | Сообщение во ввод SDK будит простаивающую сессию за 1,3 с; `canUseTool` работает; поле `origin` модель не видит — отправитель идёт в тексте. |
| 13 | `multi.mjs` | Две сессии в одном процессе Node переписываются через свой MCP-инструмент. |
| 14 | `restart.mjs`, `long.mjs` | Процесс claude умер с Host — разговор цел по `resume`, оборванный ход потерян. |
| 15 | `holder.mjs`, `ctl15.mjs`, `long.mjs` | Прообраз Keeper держит процесс; новый Host делает `attach` посреди команды — тот же ход доходит до конца. |
| 16 | `mem16.mjs` | Память: Node с SDK 72 МБ, +1 МБ на сессию; claude 225 МБ. |
| 17 | `thru17.mjs` | Чат только через Host: события SDK пачками, `session.call`, `session.prompt`, вопрос — первый ответ выигрывает. В `bypassPermissions` в `canUseTool` приходят только вопросы человеку. |
| 18 | `run18.sh`, `ctl18.mjs` | Каналы ОС (FIFO) вместо Keeper работают на Linux; на Windows так нельзя. Запуск в WSL. |
| 19 | `kernel19.mjs` | Прообраз ядра Host с модулями: два владельца — отказ старта; MCP-сервер, хук PreToolUse, вопрос, поле roster и запрос из модулей; ошибка модуля не мешает ходу. |
| 20 | `run20.mjs`, `ctl20.mjs`, `holder.mjs` | Ждущий вопрос переживает перезапуск Host: тот же `toolUseID` в `canUseTool` нового Host. |
| 21 | `reload21/` (`reload21.mjs`, `reload21b.mjs`) | Модуль перезагружается в живом `query()` без перезапуска процесса claude (Haiku 5.5, SDK 0.3.311, 31 окт.): хуки через обёртки ядра переходят на новую версию; сервер MCP — двумя вызовами `setMcpServers` (без сервера, затем с новым), 155 мс; новое событие хука не вызывается — набор хуков SDK берёт один раз в `initialize`; вызов инструмента модуля во время перезагрузки обрывается (`Connection closed`), ход продолжается. Выпуск 2 модуля берёт свою копию SDK: перед запуском `cp -r node_modules/@anthropic-ai reload21/rel2/node_modules/`. |

Опыты 15 и 20 занимают порт 38620 на 127.0.0.1.
