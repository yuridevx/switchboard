Пульт: сессии и чат

Пульт — веб-приложение владельца флота для компьютера: управлять флотом. Все сессии Claude Code на всех машинах, новая сессия, чат с любой из них, её вопросы, настройки и журнал. Это отдельное приложение со своим выпуском и адресом; телефон — второе, с другим фокусом. Общие пакеты обоих — ядро, список, карточка, чат, вопрос, уведомления — описаны в виде каркас и телефон; здесь — как они стоят в пульте и свой модуль новой сессии. Своего сервера у пульта нет: страница говорит только с relay — по wss и ключом флота этого компьютера; каждое действие исполняет модуль Host на машине сессии, каждое число приходит из roster или из ответа модуля. Аккаунты, машины, точки и журнал флота — вид пульт: флот.

panel-desk имя компьютера с пультом во флоте: одно устройство — один ключ client.panel-desk.k3f1 ключ флота этого компьютера — единственный вход; из ссылки, в хранилище браузера roster от relay: машины с их contract, сессии с полями модулей, клиенты callsign адрес сессии: site@laptop web-* общие пакеты с телефоном — описаны в каркасе switchboard-pult адрес пульта: свой Worker со статикой, папка web/pult/
