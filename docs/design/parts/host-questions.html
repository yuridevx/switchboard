приложение Claude SDK · модуль Host

questions

Вопросы сессии человеку. Сессии флота работают в режиме «разрешено всё»: команды и правки идут без спроса. Не решается автоматически только вопрос — AskUserQuestion модели или форма MCP-сервера. questions отдаёт его тому, кто дал задачу, и зрителям сессии; первый ответ выигрывает, остальные узнают, что вопрос закрыт. Ждущий вопрос переживает перезапуск Host: SDK возвращает его заново с тем же toolUseID.

toolUseID id вопроса — от SDK кто дал задачу from последнего ввода сессии зрители кто смотрит ленту сессии notify текст уведомления; пуш шлёт модуль push, если человека нет на связи

Где questions касается Claude

Слева — что questions берёт у Claude Agent SDK, в середине — услуги ядра Host и соседей, справа — что видно снаружи. Нажмите строку: подсветится цепочка.

      кадр
      
      
      Вопрос модели. Текст уведомления — отдельно, запросом notify модулю push; tag — id вопроса.

  "to": [ "phone", "panel-desk" ],
  "question": "toolu_01Hq…", "kind": "ask",
  "questions": [ {
    "question": "Какую базу мигрировать первой?",
    "header": "База", "multiSelect": false,
    "options": [
      { "label": "прод", "description": "боевая, 2 ТБ" },
      { "label": "стенд", "description": "копия за неделю" } ] } ] }

// модулю push этой машины
host.request("notify", { v: 1,
  clients: [ "phone", "panel-desk" ],
  frame: { type: "question", from: "profiles@laptop",
    notify: { title: "profiles@laptop спрашивает",
      body: "Какую базу мигрировать первой?",
      actions: [
        { title: "прод", frame: { type: "answer",
            v: 1, callsign: "profiles@laptop",
            question: "toolu_01Hq…", answers: {
              "Какую базу мигрировать первой?": "прод" } } },
        { title: "стенд", frame: { … "стенд" } } ],
      tag: "toolu_01Hq…" } } })

      Сбои и остановка
      
    
      Ждущий вопрос держит процесс claude. Модуль не отвечает за человека ни в какой ветке: нет ответа — сессия ждёт.
      
  
      
  
      
    
      
      
      
        
      сбойчто с вопросомкто поднимает
      
        
          
      Host обновляется или упалвопрос ждёт в процессе claude; новый Host после attach получает тот же toolUseID в canUseTool и шлёт question тем же адресатам из раздела questions; ответ, ушедший в старый Host без reply, у отправителя — disconnectedkeeper и SDK (опыт 20)
      
          
      ход прервалисработал signal: вопрос снят, адресатам — answered с cancelled; поздний answer — already_answeredникто
      
          
      адресат не на связиrelay кадр не доставляет; телефону с подпиской — пуш: модуль push видит по roster, что его нет; вопрос ждёт — его видно в roster как waiting, берут через question.listникто
      
          
      процесс claude умервопрос пропал вместе с оборванным ходом; answer — unknown_questionядро: resume (опыт 14)
      
          
      Host перезапущен при ждущей форме MCPформа не возвращается; answer — unknown_question; вызов инструмента MCP кончается по сроку сервера, модель видит отказчистый перезапуск
      
          
      ошибка в модуле questionsв этой сессии вопросы наружу не уходят; в roster — failed с причинойагент по журналу
      
              
      
      
    
      
    
      stop()Штатная остановка модуля: ждущие canUseTool не трогать — ни allow, ни deny, иначе это был бы ответ за человека. Раздел questions уже на диске; новый Host получит вопросы заново от SDK.
