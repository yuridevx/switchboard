push

Пуши людям, которых нет на связи. Модули машины, чей кадр идёт человеку, — questions и fleet — отдают модулю push текст уведомления запросом notify. push смотрит в roster: клиента нет на связи — просит Worker-модуль push отправить пуш этому клиенту. Подписки клиентов хранит Worker push; у модуля Host своего хранилища нет — только последний roster в памяти. С Claude push не говорит.

подписка адрес службы пушей и ключи браузера клиента; хранит Worker push клиент телефон или пульт — имя в roster: phone, panel-desk notify заголовок, текст, варианты и tag уведомления roster кто сейчас на связи — от relay Worker push шлёт пуш: подписки, ключ VAPID и шифрование только у него

Как пуш уходит в службу и где подписка — Worker-модуль push; доставка по адресу — relay; подписываются телефон и пульт.

Сбои и остановка

    
Своего состояния у модуля нет: решение — по последнему roster, подписки — у Worker push. Пуш не повторяется — пропущенное человек видит в приложении.

Эталоны push

    
Стенд Host: поддельные SDK, relay, keeper и часы; Worker push — поддельный участник relay. Номер эталона — номер теста.

  

  

    
153

      
Последний roster: panel-desk на связи, phone нет. questions зовёт notify с clients: ["phone", "panel-desk"] и кадром question.

      
Ровно один push.send: to: "push", push.to: "phone", type, from и notify кадра как есть — других полей нет. Для panel-desk — ничего. На reply ok notify отвечает ok { pushed: ["phone"] }.

      
чьё: устав — «достают до телефона», «Relay не знает модулей»; слово пользователя 31 окт. — разложение relay → relay, gate, push («подтверждаю разложение, не детали»). Подписка — у push: гейт архитектора, одно состояние — одно место (слово пользователя 31 окт.).

    
154

      
push.send для phone получает gone; следом ещё один notify для phone, phone по-прежнему нет в roster.

      
Первый notify — ok { pushed: [] } и строка в журнале «phone: подписки нет»; на второй notify снова ровно один push.send — модуль ничего не запомнил и ничего не записал на диск.

      
чьё: факт — RFC 8030: 404 и 410 — подписки больше нет; устав — «Система ловит, агент чинит»: код только обнаруживает ошибку и пишет в журнал. Подписка — у push: гейт архитектора, одно состояние — одно место (слово пользователя 31 окт.).

    
155

      
phone в последнем roster на связи; questions зовёт notify для phone.

      
push.send не отправлен, notify — ok { pushed: [] }.

      
чьё: устав — «достают до телефона»: пуш — для закрытого приложения; «Relay не знает модулей… кадр с to доставляет по адресу».
