модуль приложения Claude SDK

slots

Горячая подмена аккаунта при лимитах. Host — программа на каждой машине, через которую идут все сессии Claude Code; slots — его модуль. Слот — папка входа на машине по имени: main, bot. Сессии работают в слоте, а не на аккаунте. Аккаунт слота подошёл к порогу — slots просит accounts положить в папку слота вход следующего аккаунта из запаса, и следующий вызов модели всех сессий слота идёт уже на нём: тот же процесс, тот же ход, без перезапуска.

слот main — папка входа, общая для своих сессий запас аккаунты слота по порядку порог 95 % за 5 ч, 98 % за неделю подмена вход следующего — в папку слота окно rateLimitType и resetsAt — у каждого аккаунта своё

Вход аккаунтов, их папки и лимиты — accounts; из чего собирается запуск сессии — profiles.

Слот, запас и сессии

У слота main три аккаунта. Один сидит в слоте — на нём работают все сессии слота; остальные ждут в запасе по порядку.

одно местоАккаунт живёт в своей папке или в слоте, не в двух сразу. Вход переносит accounts, slots только решает, кого и когда.
сессии делят слотВсе сессии слота переходят на новый аккаунт вместе: лимит общий у аккаунта, держать половину сессий на исчерпанном незачем.
без слота — вход машиныСессия, открытая без слота, работает на входе машины по умолчанию, как Claude Code в терминале. Подмены у неё нет; в запас этот вход не берётся.

Подмена за секунду

Две сессии в слоте main, у infirex кончается окно в пять часов. Пройдите по шагам: что slots видит в потоке, что просит у accounts и что читает claude.

Прогон: слот с тремя аккаунтами

    
Порог — 95 % за 5 ч или 98 % за неделю. Следующий — первый по порядку запаса ниже порога. Отказ модели — подмена сразу и «Продолжай» оборванному ходу. Все у порога — слот ждёт ближайшего сброса и продолжает сам. Данные примерные.

        Решения
        
    
        Пять развилок дизайна слотов. Выбранное — в рамке.
        
  
        
  
        
    
        
      
        Как менять аккаунт у живой сессии
        
      
        
        
        Перезапуск процесса с другим аккаунтом. Ответ обрывается, claude.ai — новая сессия.
        
        
        Заменить файл входа в папке слота. Проверено пробами.
        
      
        
    
        
    
        
      
        Чей слот
        
      
        
        
        Свой слот у каждой сессии. Запас одного аккаунта делят слоты — нужен общий учёт.
        
        
        Слот — на машине, по имени; сессии его делят. Слотов может быть несколько: main, bot.
        
      
        
    
        
    
        
      
        Когда менять
        
      
        
        
        Только при отказе. Ход рвётся, его продолжают сообщением.
        
        
        У порога заранее; при отказе — подмена сразу и «Продолжай».
        
      
        
    
        
    
        
      
        Вход машины по умолчанию — в запас?
        
      
        
        
        Можно. Кто первым обновит токен, выкинет из входа второго — например, ваш Claude Code в редакторе.
        
        
        Нельзя. В запас — только аккаунты, вошедшие с пульта в свою папку.
        
      
        
    
        
    
        
      
        Кто выбирает следующий аккаунт
        
      
        
        
        Пульт: видит лимиты всего флота, но без связи подмены не будет.
        
        
        Host на машине, сам и сразу. Пульт подсказывает расход тех же аккаунтов на других машинах.
        
      
        
    
        
  
        

        



        
  
        
    
        С чем slots работает
        
    
        Из потока сессии slots читает два сообщения — о лимите и об ошибке лимита. В процесс даёт одну переменную окружения — папку слота. Своего о входах и окнах он не хранит: где чей вход и окна аккаунтов — записи accounts. Жёлтая метка — вне документации Claude Code, по исключению для аккаунтов.
