Ключи флота: один раз на все машины
Ключ API провайдера или Anthropic заводится один раз и виден слотом на каждом компьютере. Вход Claude по ссылке остаётся на своей машине.

  
  
Делить вход Claude между машинами нельзя: refresh-токен меняется при каждом обновлении, и вторая машина с той же копией теряет вход. Поэтому через флот идут только ключи API. Ключ флота — сам себе слот: запасных и подмены у него нет.
