Фронт на живом флоте

Страница собирается из рабочего дерева на вашей машине и работает с настоящим флотом: тестовым или продом. Правка кода видна на экране примерно через 2 секунды, запись доходит до флота по-настоящему. Это тот же локальный сервер, что показывает прототипы дизайна, с одним новым ключом.

Как это выглядит

$ npm run front test фронт: тест · заметки: dist/front-test-4801/notes.json в чат: http://localhost:4801/app/pult/#invite=k2a9… снимки: http://localhost:4801/app/pult/#invite=p7c1… $ npm run front prod фронт: прод · заметки: dist/front-prod-4802/notes.json в чат: http://localhost:4802/app/pult/#invite=m4d0… $ npm run front test -- --app pult,phone --port 4811 # вторая сессия рядом

Клавиша C и клик по элементу оставляют комментарий, агент получает его и правит код, страница обновляется сама. Вкладка подписана флотом: «pult · тест», «pult · прод».

Страница из дерева может обгонять флот. Запрос, которого флот ещё не знает, получает отказ словом на экране, поэтому бекенд идёт на флот раньше фронта.

Один адрес, один пропуск

:4800прототип дизайна
:4801разработка на тесте
:4802разработка на проде
:4811вторая сессия, порт явно

Браузер хранит пропуск отдельно для каждого адреса, поэтому тест и прод не смешиваются. Пропуск живёт, пока работает сервер: запуск отзывает старый и выдаёт приглашение, остановка отзывает. После перезапуска ссылка покажет экран «Заменить пропуск», это один клик.

Порт занимается раньше, чем трогаются пропуска. Запуск на занятом порту заканчивается отказом словом, чужая работающая страница не теряет вход.
