# Отложенные дизайны

Дизайн здесь — не план текущей работы. Текущее устройство описывает устав (`CLAUDE.md`), а не эти страницы.

| дизайн | статус | что внутри |
|---|---|---|
| [any-agent.html](any-agent.html) «Любой агент во флоте» | отложен словом пользователя 3 нояб. 2026 | Host как клиент ACP, агенты Kimi и Muse, зрелость адаптеров, опыты 11 из 11, чат на событиях ACP, два флота на одном компьютере, A2A на границе флота, план работ |

Из этого дизайна в работу ушёл только этап 0 — он в бэклоге: два флота на одном компьютере и история после сжатия контекста. Остальное не делается, пока пользователь не скажет.

При возврате снять заново: версии адаптеров, заявки и отставание от агентов. Числа в дизайне — на 3 нояб. 2026, адаптеры выходят раз в несколько дней.

Открыть с метками и комментариями:

    node docs/designs/serve-design.mjs docs/designs/any-agent.html

Страница откроется на http://localhost:4790. Метки «прочитал» и комментарии сервер пишет в `any-agent.notes.json` рядом со страницей.
