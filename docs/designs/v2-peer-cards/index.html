Карточки входящего от флота

Всё, что сессии приходит от флота, в ленте разговора стоит карточкой своего вида. По цвету полосы и значку видно, что это, по шапке — от кого и когда. Нажмите на вид.

Шесть видов — одна карточка

Один компонент, шесть обликов. Слово вида, значок и цвет полосы берутся из одной таблицы; вид называет машина, страница получает его готовым полем и текст не разбирает.

Как это выглядит: настоящий код страницы на моке

Эталоны

В ленте входящее каждого из шести видовчьё: слово пользователя 16 нояб. — «нарисуй фронтенд карточки для всех новых форматов сообщения»
→
Карточка с именем «вид от отправителя»; у пяти видов — слово вида, у сообщения соседа слова нет
Отправитель — сессия; отправитель — машиначьё: код — адрес сессии открывает её разговор
→
Ссылка на разговор этой сессии; у машины ссылки нет
Обращение службы компьютерачьё: договор — вид и ключ обращения приходят полями
→
В шапке — «вид · ключ»
Вопрос дочери; сессия ответила на него инструментом answerчьё: устав — в интерфейсе только то, что несёт информацию постоянному пользователю
→
Строки вопроса стоят как пришли; под текстом — «отвечено: …»; номера вопроса на карточке нет

Явное · отвечен ли вопрос дочери, из ленты было не понять · «отвечено: …» берётся из вызова инструмента answer в этом же разговоре — новых запросов нет Не добавлено: ответ человека на вопрос дочери прямо с карточки — вопрос уже стоит карточкой с кнопками в разговоре самой дочери, второй способ входа не нужен. Варианты вопроса кнопками — для этого странице пришлось бы разбирать текст, формат которого знает только машина. Развилки пользователю: нет. Вердикт (автономный режим): делай

Порядок реализации

  1. Карточка входящего в ленте: шесть обликов, отправитель-ссылка, вид и ключ обращения, «отвечено» у вопроса, откат значком.
    Готово: эталон карточек зелёный; тесты страницы 271 из 271; снимки 1280 и 390 в двух темах — ошибок страницы 0, горизонтальной прокрутки нет.
  2. Тестовый флот: страница выложена, живая проверка страницы.
    Готово: ошибок страницы 0; в ленте настоящей сессии с итогом дочери — карточка «Итог».
  3. Прод — по вашему слову «и потом сразу в прод».
    Готово: страница прода отдаёт новую сборку; ошибок страницы 0.
