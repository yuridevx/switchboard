Сессия одним вызовом снимает с себя родителя: в списке встаёт в корень проекта и больше ему не отчитывается.

Путь вызова

Один вызов — три следствия. Родителя нет в документе; строка в списке встаёт в корень; итоги ходов прежнему родителю не идут. Нажмите на блок или стрелку.

Порядок реализации

  1. Договор и машина: parent: null в правке документа убирает родителя; напарнику — отказ словом; строка в описании инструмента и в справке сессий.
    Готово: npx vitest run test/core.test.ts в части машины — 16 из 16, новый эталон 1.
  2. Страница: под кем стоит сессия — только родитель из документа; подделка флота пишет родителя так же, как машина.
    Готово: npx vitest run src/session/iter2.test.ts src/screens/screens.test.tsx — 78 из 78, новый эталон 1; мест с правилом 2 → 1.
  3. Слияние; на тестовый флот выкладывает CI; живой шаг: дочерняя снимает родителя инструментом и встаёт в корень списка в браузере.
    Готово: живой список зелёный, шаг «дочерняя сняла родителя» — 1 снимок.
  4. Прод — по слову пользователя «фаст в прод».
    Готово: выкладка на прод зелёная, тот же живой шаг на проде — 1.
