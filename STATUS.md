# Switchboard — карта и состояние

Система с нуля по дизайну `docs/designs/from-scratch/index.html`. Старая система — тег `v1`.

## Части

| папка | что | чем проверяется |
|---|---|---|
| `protocol/` | `@sb/protocol`: конверт кадра, адреса, пропуск `флот:номер:секрет`, договор-код (`request`, `frame`, схемы zod), журнал одной формы, общий клиент (`createApi`, `httpTransport`, `socketLink`) | `cd protocol && npx vitest run` |
| `platform/` | Worker `sb2-platform`: объект флота (люди, пропуска, проекты, картина, сокеты страниц) и объект машины (сокеты Host, Keeper, зрителей; доставка кадров). Вход привязки для служб — `platform/src/contract.ts` | vitest в пуле Workers |
| `services/` | Worker `sb2-services` без состояния: вход `POST /call`, сервер MCP `/mcp`, файлы страницы, проход сокетов `/f/*` и `/m/*` в платформу; модули `src/modules/<имя>/`; записи модуля — объект `Records` на модуль и флот (архив — на машину); файлы — R2 | vitest в пуле Workers |
| `host/` | Node + Claude Agent SDK: ядро (сессии, документ, связь, хранилище) и модули chat, accounts, profiles, points, proxy, shell, incidents, machine | vitest со стендом (поддельные SDK, связь, держатели) |
| `keeper/` | Go: служба ОС, держит Host и себя, держатели процессов | `go test` |
| `web/` | React 19 + Mantine 9 + Vite: одна страница, две раскладки; мок флота для прототипа | vitest + снимки `npm run shots` |
| `tools/` | гейт импортов, раннер проверки частей, выкладка одной командой, живая проверка флота одним списком | `node tools/test/run.mjs tools` |

## Правила для исполнителей

- Один адрес флота: всё идёт в службы (`/call`, `/mcp`, `/f/<флот>`, `/m/<флот>/<машина>`, страница); службы зовут платформу привязкой.
- Запрос описан один раз в `protocol/src/contracts/`. Новое имя — туда, с хозяином; обработчик берёт уже проверенный ввод. Договор правится только добавлением; перед правкой перечитать файл: его правят и другие.
- Модуль импортирует чужое только через `@sb/protocol` и вход пакета. Циклов нет: службы → платформа → протокол.
- Каждый запрос несёт `trace`; каждая часть на обратном пути дописывает в `reply.spans` свой отрезок `{part, ms}`; на каждый запрос — одна строка журнала (`logger` из протокола) с `type`, `from`, `to`, `ms`, `ok`, `word`, `trace`.
- Ошибка обработчика — отказ `module_failed` и строка журнала; модуль не выключается. Отказ — `throw new Refusal(слово, причина)`.
- У каждой операции предел (`within`, `CALL_MS`) и штатная остановка.
- Просто: только ожидаемые ветки; без повторов, запасных режимов и обратной совместимости.
- Язык: идентификаторы по-английски, комментарии и тексты интерфейса по-русски.
- Тесты: эталон закрепляет одно свойство на зафиксированном входе. На этой машине: запускать из пути с большой `D:/`; `setTimeout(0)` спит около 10 мс.
- Зависимости уже поставлены в корне репо. Новая зависимость — в `package.json` своей папки и `npm install` из корня (если упал — повторить: рядом могут ставить другие). `npm install-scripts approve <пакет>` — если нужен установочный скрипт.
- Свои файлы — только в своей папке. Не коммитить: коммиты делает главная сессия.
- Ресурсы Cloudflare v2 — с приставкой `sb2-`; на флот никто не выкладывает с компьютера: выкладывает CI. Секреты — из `~/.switchboard-dev/v2-cloudflare.env`, не в репо и не в argv.

Путь в прод (17 нояб. 2026, дизайн `docs/designs/fast-path`, https://claude.ai/artifact/2qi4VPLHEYr4Z8a5EFXWhU): проверяет и выкладывает CI, с компьютера сессии на флот ничего не идёт. Файлы сессии (17 нояб. 2026, дизайн `docs/designs/v2-show`, https://claude.ai/artifact/1XwL1X1ZVc1Y3iyDarYu9F): содержимое файла лежит в бакете под хэшем SHA-256 (`files/<флот>/<хэш>`), в сообщении, ленте, журнале и истории — `{name, hash, size}`. Службы, модуль `files`: `files.put` — ссылки на загрузку для хэшей, которых в хранилище нет; `files.get` — ссылка на чтение, с именем — вложением; `files.site` — список «путь → хэш» сайта (объект бакета `sites/<номер>.json`); сайт сессии отдаёт Worker по адресу `/s/<номер>/` без пропуска, с заголовком песочницы. Host, модуль `host-files`: инструменты сессии `file_send {to, path, title}` и `site_publish {to, dir, title}` — только от себя (`not_self`); номер сайта выводится из секрета машины, позывного и папки; файлы сообщения (`message.files`) встают в `uploads/` папки сессии со сверкой хэша, сессии приходит строка «Загружены файлы в папку сессии: …», ленте и истории Host отдаёт разобранное (`files` у события, текст без строки). Приём докачивается: файл, не уложившийся в предел запроса (2 мин), остаётся черновиком `uploads/.<хэш>.part`, повтор сообщения продолжает с места. Блоков-картинок в ввод не кладёт никто (отказ `bad_attachment` ушёл); обращения служб компьютера кладут файл сразу в хранилище. Обмен с хранилищем по ссылкам — один на файлы и архив точек (`host/src/modules/files/store.ts`, `services/src/r2.ts: uploadLinks`). Страница: любой файл из поля ввода, файл и сайт в ленте на месте вызова инструмента, скачивание, один лист «целиком», схема из блока `mermaid`, одно правило вида показа (`showKind`). Перед выкладкой на новый флот — `node tools/deploy/cors.mjs [prod]` (доступ к бакету из браузера). Живая проверка — `SB2_KEY=… SB2_MODEL=… node tools/fleet/live-files.mjs test cli <машина>` (7 шагов в Chrome; `SB2_BIG_MB` — размер большого файла). Сценарий на моке — `node docs/designs/v2-show/shots.mjs` (40 шагов). Оговорки: отправка сессией нового большого файла — один PUT под пределом запроса, докачки в эту сторону нет; `shell.run` по-прежнему отдаёт файлы скрипта содержимым в кадре.

Аккаунты и модели (15 нояб. 2026, дизайн `docs/designs/v2-accounts`, https://claude.ai/artifact/HCfNrYCPYLyw5LW3VC7Jps; ветка выпуска `release/v2-accounts`): очередей аккаунтов, входов Claude на машинах и Remote Control нет — аккаунт Claude это ключ флота с протоколом `claude` (имя — почта, значение — годовой токен `claude setup-token`), он заводится один раз на флот запросом `keys.set`; у процесса сессии вместо токена слово-заглушка, настоящий токен ставит прокси машины. Аккаунт сессии выбирает машина (`host/src/modules/accounts/limits.ts: choose`): годен → остаток → счёт = остаток ÷ часы до сброса ÷ (1 + тёплые сессии) → лучший; сессия держится аккаунта, пока кэш её разговора тёплый, отказ лимита Claude уводит тот же вызов на следующий аккаунт и сессии не достаётся, числа лимитов — из заголовков ответов Claude. Документ сессии называет провайдера и точную модель — `key` (`claude` или имя ключа флота) и `model` из каталога `keys.models`: без них отказ `key_required` / `model_required`, модели нет в каталоге — `no_model`, «/model слова» сообщением меняет модель (`many_models`, `no_model`); у ключа флота поле `protocol`, полей `model`, `models`, `window` нет. Решения и события аккаунта — строки журнала машины (`route`, `account.moved`, `account.full`, `account.closed`, `account.token`, `call`), журнал уходит в ClickHouse (`log.write`) и читается `log.query`; в строке сессии — `cache {until, compact}` и `answers`, ядро само сжимает разговор от 200 К на 54-й минуте простоя (`host/src/core/session.ts`). Экран «Флот → Аккаунты» — столбцы аккаунтов, флаг «беречь запас Fable», лента переходов; в разговоре аккаунта и лимитов нет; эталоны — `host/test/accounts.test.ts`, `host/test/cache.test.ts`.

Низ разговора (15 нояб. 2026, дизайн `docs/designs/v2-chatbar`, https://claude.ai/artifact/VXrJ6XL9XPEtwzJubUeNHT; ветка выпуска `release/v2-chatbar`): значения сессии под полем ввода — ряд значков (режим, модель, усилие ступеньками, кусочки, кольцо контекста, час кэша), слово значения — в подсказке и в меню; в узкой колонке ряд переходит в краткий вид, действия — второй строкой. Срочностей сообщения две — `now` и `next`, набор объявлен один раз в договоре (`Priority`); пока идёт ход, обе — кнопками поля ввода: стрелка — следующим, молния — сейчас. Ждущее сообщение помечено «в очереди». Панель сессии после загрузки закрыта и открывается кнопкой ряда или клавишей I; настройки «Поля под вводом» и полей значений в листе панели на телефоне нет.
