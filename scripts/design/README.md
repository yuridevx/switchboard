# Сервер дизайна

Страница дизайна, настоящее веб-приложение этого дерева и заметки — с одного локального адреса. Два режима страницы:

- прототип — есть `mock.ts`: данные флота живые, новое по договору дизайна отвечает мок, флот не меняется;
- разработка фронта — мока нет, назван флот: записи идут во флот по-настоящему, бекенд — выложенный на этот флот.

## Команды

```
node scripts/design/serve.mjs docs/designs/<имя> 4800 [--app pult,phone] [--fleet test]   # сервер; печатает ссылки «в чат» и «снимки»
npm run front test|prod [-- --app pult,phone --port 4811]                                 # разработка фронта на флоте
node scripts/design/watch.mjs <папка>                                                     # ждёт новый комментарий (до 6 ч), печатает и выходит
node scripts/design/pass.mjs close <папка> [--fleet test]                                 # отозвать пропуска папки после жёсткого выхода
```

- `/` — страница дизайна `index.html`; `/app/<приложение>/` — приложение.
- Прототип включается, если в папке есть `mock.ts`; приложение по умолчанию — `pult`, флот — прод. Нужен `web/<имя>/stand/parts.ts` с `export function <имя>Parts()`. Нет частей — сервер не стартует, отказ `no_stand` с подсказкой. Мока нет и флот не назван — отказ `no_mock`.
- Вход во флот — пропуском агента `~/.switchboard-dev/<флот>-agent.pass` (или `$SWITCHBOARD_DEV_DIR`). Порт занимается первым: занят — отказ `port_taken`, пропуска не тронуты. Затем старые пропуска `design-<имя>` и `design-<имя>-shots` отзываются, выдаются новые приглашения: «в чат» — ссылка пользователю, «снимки» — браузеру сессии. Остановка сервера (SIGINT, SIGTERM) отзывает их. После перезапуска ссылка покажет экран «Заменить пропуск»: браузер помнит прежний.
- Страница обновляется сама при правке любого файла её сборки; ошибка сборки — тост с причиной, страница остаётся на прежней сборке.
- Комментарии: на странице дизайна — поле у блока; в приложении — кнопка «Комментировать» внизу слева или клавиша C в любой раскладке, клик по элементу.

## Разработка фронта

`npm run front test` — порт 4801, `npm run front prod` — 4802: свой адрес — свой пропуск в браузере, тест и прод не смешиваются. Вторая сессия рядом — свой порт `--port`. Папка заметок — `dist/front-<флот>-<порт>/`, по ней же `watch.mjs` и `pass.mjs close`.

Запрос, которого флот ещё не знает, получает отказ словом: бекенд идёт на флот раньше фронта.

Агент работает на тесте ссылкой «снимки». На проде агент ссылки не получает: страница там для человека, запись — как на его пульте; читать данные прода агент может через прототип.

## Папка дизайна `docs/designs/<имя>/`

- `index.html` — страница дизайна; без `<!doctype>` сервер оборачивает её, как публикация.
- `notes.json` — пишет сервер: `{ marks: { <блок>: true }, comments: [{ id, at, text, where }] }`; `where.page` — `doc` (и `block`) или `app:<имя>` (и `hash`, `selector`, `element`, `w`, `theme`).
- `mock.ts` — `export default { … } satisfies ProtoMock<State>` (`@proto/api`):
  - `owns` — запросы договора дизайна: их отвечает только мок, в прод они не уходят;
  - `state()` — состояние мока в памяти страницы; `answer(f, ctx)` — ответ по кадру и `ctx.state`. Взаимодействия с новым меняют `ctx.state`, следующие ответы показывают итог. `ctx.real(f)` — настоящий ответ прода;
  - `harmless` — записи, которые прод не меняют: идут в прод;
  - `roster(r, state)` — правка roster одной машины;
  - `workers` — службы, которых в проде ещё нет: имя → адрес-заглушка; кадры к ним отвечает только мок;
  - `init(ctx)` — данные до старта.

  Мок молчит на запрос из `owns` или на кадр к службе-заглушке — ошибка прототипа: тост «прототип: мок не отвечает <тип>», то же в консоли, отказ `no_mock`.
- `data.mjs` — необязательно: `export function <имя>(params)` — данные с диска машины, в моке — `ctx.data("<имя>", params)`.

## Что уходит в прод

Ядро страницы отдаёт каждый запрос модуля и каждый roster шву `StartOptions.seam` (`seam.ts`):

- чтения и безвредные записи — в прод;
- ответы мока — вместо прода;
- `prefs.set` хранится в памяти страницы;
- остальные записи не отправляются: тост «прототип: не отправлено» с телом запроса.

Сборка страницы — та же, что у стенда снимков (`scripts/shots/stand.mjs`), вход свой: `entry.tsx`.
